# README screenshots

The images in `readme/` are Android system screenshots of Comet Mobile running on an API 36 emulator. The profile list and editor use a reserved example hostname and a TEST-NET address. The landscape console connects to a loopback fixture and decodes a synthetic H.264 colour-bar signal. The video pattern was generated for these screenshots.

The earlier NanoKVM illustrations and screenshots belong to the [upstream project](https://github.com/andrewginns/nanokvm-mobile/tree/a4e829b6888d622de4d5ec1f3012a26c402d5b2a/docs/images).
